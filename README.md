# Project 3 – SQL Data Analysis

## Description

This project focuses on analyzing an e-commerce dataset using SQL queries.

The objective is to extract meaningful insights from the cleaned dataset by using SQL commands such as `SELECT`, `LIMIT`, `GROUP BY`, and `ORDER BY`, along with aggregate functions such as `COUNT()`, `SUM()`, and `AVG()`.

## Dataset

The analysis is performed using the cleaned dataset:

Cleaned_Dataset

The dataset contains e-commerce order information such as:

* OrderID
* Date
* CustomerID
* Product
* Quantity
* UnitPrice
* ShippingAddress
* PaymentMethod
* OrderStatus
* TrackingNumber
* ItemsInCart
* CouponCode
* ReferralSource
* TotalPrice

## SQL Analysis Performed

### 1. View Dataset

The complete dataset and the first 10 records are displayed using `SELECT` and `LIMIT`.

SELECT * FROM cleaned_dataset;

SELECT * FROM cleaned_dataset LIMIT 10;

### 2. Total Number of Orders

`COUNT()` is used to calculate the total number of orders.

SELECT COUNT(*) AS total_orders
FROM cleaned_dataset;


### 3. Total Revenue Generated

`SUM()` is used to calculate the total revenue generated from all orders.

SELECT SUM(TotalPrice) AS total_revenue
FROM cleaned_dataset;

### 4. Average Order Value

`AVG()` is used to calculate the average value of an order.

SELECT AVG(TotalPrice) AS average_order_value
FROM cleaned_dataset;

### 5. Top Selling Products

Products are grouped together and their total quantity sold is calculated. The results are sorted from highest to lowest quantity.

SELECT Product,
       SUM(Quantity) AS total_quantity_sold
FROM cleaned_dataset
GROUP BY Product
ORDER BY total_quantity_sold DESC;


### 6. Revenue by Product

The total revenue generated by each product is calculated using `SUM()` and `GROUP BY`.

SELECT Product,
       SUM(TotalPrice) AS revenue
FROM cleaned_dataset
GROUP BY Product
ORDER BY revenue DESC;

### 7. Orders by Payment Method

The number of orders made through each payment method is calculated.

SELECT PaymentMethod,
       COUNT(*) AS total_orders
FROM cleaned_dataset
GROUP BY PaymentMethod
ORDER BY total_orders DESC;

### 8. Order Status Analysis

Orders are grouped according to their status to understand the distribution of different order statuses.

SELECT OrderStatus,
       COUNT(*) AS total_orders
FROM cleaned_dataset
GROUP BY OrderStatus
ORDER BY total_orders DESC;

### 9. Highest Value Orders

The top 10 highest-value orders are identified by sorting orders according to `TotalPrice`.

SELECT OrderID,
       Product,
       TotalPrice
FROM cleaned_dataset
ORDER BY TotalPrice DESC
LIMIT 10;

### 10. Referral Source Performance

The number of orders and total revenue generated by each referral source are calculated.

SELECT ReferralSource,
       COUNT(*) AS total_orders,
       SUM(TotalPrice) AS total_revenue
FROM cleaned_dataset
GROUP BY ReferralSource
ORDER BY total_revenue DESC;

### 11. Coupon Usage Analysis

The number of times each coupon code was used is calculated.

SELECT CouponCode,
       COUNT(*) AS usage_count
FROM cleaned_dataset
GROUP BY CouponCode
ORDER BY usage_count DESC;

### 12. Average Items Per Cart

The average number of items per cart is calculated using `AVG()`.

SELECT AVG(ItemsInCart) AS avg_items_per_cart
FROM cleaned_dataset;

## How to Run

### 1. Open MySQL Workbench

Open MySQL Workbench and connect to your MySQL server.

### 2. Create or Select the Database

Select the database containing the `cleaned_dataset` table.

For example:

USE ecommerce_analysis;

### 3. Import the Dataset

Import the cleaned dataset and create a table named:

cleaned_dataset

### 4. Run the SQL Queries

Open the SQL file containing the analysis queries and execute the queries individually or together.

The queries will generate results for orders, revenue, products, payment methods, order statuses, referral sources, coupons, and cart analysis.
